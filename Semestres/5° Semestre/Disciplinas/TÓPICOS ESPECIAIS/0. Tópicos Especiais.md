> Tema do semestre: **desenvolvimento de jogos digitais 2D para a Web**.

## Plano de Ensino

**OBJETIVOS**
Ao concluir esta unidade curricular, o discente será capaz de:
- Identificar tecnologias e padrões Web para o desenvolvimento de jogos digitais em rede;
- Projetar um jogo digital 2D para a Web;
- Aplicar recursos visuais e sonoros para compor um jogo digital.

**CONTEÚDOS**
Arquitetura de jogos digitais 2D para a Web. APIs Web voltadas para interação com o usuário e comunicação em tempo real. Conceitos de game design: enredo, personagens, mídias (áudio e imagem). Construção de mapas e cenas. Animação e física com sprites: gravidade e colisão. Motores de jogos.

**METODOLOGIA**
Metodologia baseada em projeto para o desenvolvimento de um jogo Web ao longo do semestre, com **entregas regulares de progresso** como avaliação.
