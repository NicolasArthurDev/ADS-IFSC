Nesta atividade, você irá iniciar um backend capaz de fornecer datas e horários. Esse backend disponibiliza dois endpoints:

- **/data**: uma requisição GET neste endpoint tem como resposta a data de hoje no formato DD/MM/AAAA. A data deve ser retornada em um objeto JSON com este formato (isto é um exemplo):
    
    {"data": "10/02/2026"}
    
- **/horario**: uma requisição GET neste endpoint tem como resposta o horário atual no formato HH:MM:SS.O horário deve ser retornada em um objeto JSON com este formato:
    
    {"horario": "19:01:37"}
    
- **/agora**: uma requisição GET neste endpoint tem como resposta a data e horário atual. A resposta deve ser em um objeto JSON com este formato:
    
    {"horario": "19:01:37", "data": "10/02/2026"}
    

Para esta atividade, caso sinta necessidade, você pode consultar a [documentação sobre as classes HttpServer, HttpHandler e HttpExchange](https://moodle.ifsc.edu.br/mod/page/view.php?id=15917).

#### Data e horário

Para obter data e horário em um programa Java, use a API java.time. Ela contém as classes LocalDate, LocalTime e LocalDateTime, além de formatadores para mostrar data e horário no formato desejado. Por exemplo, para mostrar a data de hoje pode-se fazer isto:

```java
  LocalDate hoje = LocalDate.now();  
  var formato = DateTimeFormatter.ofPattern("dd/MM/yyyy");  
  String data_ = formato.format(hoje);  
  System.out.println(data_);
```

... o que irá apresentar o seguinte: _10/02/2026_
