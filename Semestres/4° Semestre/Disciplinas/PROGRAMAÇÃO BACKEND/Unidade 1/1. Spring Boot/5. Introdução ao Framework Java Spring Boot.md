#### 5. Experimentando uma pequena alteração

A aplicação inicial retorna um resultado com tipo predefinido _text/html_. Sendo assim, se o processamento de uma requisição retornar um código HTML, o navegador deve conseguir renderizá-lo como esperado. Experimente alterar o método _hello_ da seguinte forma:

@RequestMapping("/hello")  
public String hello() {  
    return "<html><body><h1>Hello world !</h1></body></html>";  
}

Reinicie sua aplicação, e tente novo acesso. O resultado deve ser uma página como esta:

![spring boot app hello](https://moodle.ifsc.edu.br/pluginfile.php/40523/mod_page/content/15/spring-boot-hello-html.png)

Se você quiser alterar o tipo de conteúdo da resposta informado ao cliente (i.e. o valor do cabeçalho _Content-type_), faça esta modificação:

@RequestMapping(value="/hello", produces="text/plain")  
public String hello() {  
    return "<html><body><h1>Hello world !</h1></body></html>";  
}

Observe que a anotação _@RequestMapping_ agora tem dois parâmetros:

- _value_: a URI da requisição
- _produces_: o tipo do conteúdo retornado

Reinicie sua aplicação, e tente novo acesso. O resultado deve ser uma página como esta:
