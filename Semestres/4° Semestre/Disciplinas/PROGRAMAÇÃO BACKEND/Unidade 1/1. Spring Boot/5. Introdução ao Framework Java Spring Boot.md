#### 5. Experimentando uma pequena alteração

A aplicação inicial retorna um resultado com tipo predefinido _text/html_. Sendo assim, se o processamento de uma requisição retornar um código HTML, o navegador deve conseguir renderizá-lo como esperado. Experimente alterar o método _hello_ da seguinte forma:

```java
@RequestMapping("/hello")  
public String hello() {  
    return "<html><body><h1>Hello world !</h1></body></html>";  
}
```


Reinicie sua aplicação, e tente novo acesso. O resultado deve ser uma página como esta:

![[Pasted image 20260308202535.png]]

Se você quiser alterar o tipo de conteúdo da resposta informado ao cliente (i.e. o valor do cabeçalho _Content-type_), faça esta modificação:

```java
@RequestMapping(value="/hello", produces="text/plain")  
public String hello() {  
    return "<html><body><h1>Hello world !</h1></body></html>";  
}
```

Observe que a anotação _@RequestMapping_ agora tem dois parâmetros:

- _value_: a URI da requisição
- _produces_: o tipo do conteúdo retornado

Reinicie sua aplicação, e tente novo acesso. O resultado deve ser uma página como esta:

![[Pasted image 20260308202554.png]]

## Tutorial: use o IntelliJ para criar um backend que fornece arquivos usando Spring Boot

No IntelliJ selecione File->New->Project. A tela de configuração do novo projeto deve ser como esta:

O projeto será criado e então aberto, mostrando a seguinte estrutura de pastas e arquivos:

#### 2. Crie sua primeira aplicação

Edite _Demov2Application.java_ para que sua aplicação retorne uma mensagem "_Hello World !_" em resposta a requisições HTTP:

```java
package org.pbe.demov2;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@SpringBootApplication
@RestController
public class Demov2Application {

    public static void main(String[] args) {
        SpringApplication.run(Demov2Application.class, args);
    }

    @RequestMapping("/hello")
    public String hello() {
        return "Hello world !";
    }
}
```
