Os navegadores da Web se comunicam com servidores da Web usando o HyperText Transfer Protocol (HTTP). Quando você clica em um link em uma página da Web, envia um formulário ou executa uma pesquisa, uma solicitação HTTP é enviada do seu navegador para o servidor de destino.

A solicitação inclui uma URL que identifica o recurso afetado, um método que define a ação necessária (por exemplo, obter, excluir ou postar o recurso) e pode incluir informações adicionais codificadas em parâmetros de URL (os pares de campo-valor enviados por meio de uma sequência de consulta), como dados POST (dados enviados pelo método HTTP POST) ou em cookies associados.

Os servidores da Web aguardam mensagens de solicitação do cliente, processam-nas quando chegam e respondem ao navegador da Web com uma mensagem de resposta HTTP. A resposta contém uma linha de status que indica se a solicitação foi bem-sucedida ou não (por exemplo, "HTTP/1.1 200 OK" para sucesso).

O corpo de uma resposta bem-sucedida a uma solicitação conteria o recurso solicitado (por exemplo, uma nova página HTML ou uma imagem), que poderia então ser exibido pelo navegador da Web.

#### Backend: servidor web e aplicação web

Um cliente interage com um servidor, que processa e responde requisições de acordo com a lógica de uma aplicação web. O servidor web é responsável pelos detalhes de comunicação HTTP, tais como receber, decompor e encaminhar requisições para processamento, e devolver as respostas a essas requisições. A aplicação web é responsável pela funcionalidade de fato, ditando que requisições são possíveis de serem atendidas, e como devem ser processadas e respondidas.

O conjunto formado por servidor web e aplicação web é chamado de _backend_. Etimologicamente, _backend_ significa a _**parte por trás**_ de uma aplicação. Por outro lado, _frontend_ significa a _**parte da frente**_, que interage diretamente com o usuário. Sendo assim, a rigor _backend_ é a _**parte da aplicação web que não é visível diretamente pelos usuários**_.

#### Programação do lado do servidor

A programação do lado do servidor é muito útil porque nos permite entregar informações personalizadas para usuários individuais de forma eficiente e, assim, criar uma experiência de usuário muito melhor.

Empresas como a Amazon usam a programação do lado do servidor para construir resultados de pesquisa para produtos, fazer sugestões de produtos direcionados com base nas preferências do cliente e hábitos de compra anteriores, simplificar compras, etc.

Os bancos usam a programação do lado do servidor para armazenar informações de conta e permitir que apenas usuários autorizados visualizem e façam transações. Outros serviços como Facebook, Twitter, Instagram e Wikipedia usam a programação do lado do servidor para destacar, compartilhar e controlar o acesso a conteúdo interessante.

Alguns dos usos e benefícios comuns da programação do lado do servidor estão listados a seguir.

##### Armazenamento e entrega eficientes de informações

Imagine quantos produtos estão disponíveis na Amazon e imagine quantas postagens foram escritas no Facebook? Criar uma página estática separada para cada produto ou postagem seria completamente impraticável. A programação do lado do servidor nos permite armazenar as informações em um banco de dados e construir e retornar dinamicamente HTML e outros tipos de arquivos (por exemplo, PDFs, imagens, etc.). Também é possível retornar dados (JSON, XML, etc.) para renderização por estruturas da web do lado do cliente apropriadas (isso reduz a carga de processamento no servidor e a quantidade de dados que precisa ser enviada).

O servidor não se limita a enviar informações de bancos de dados e pode, alternativamente, retornar o resultado de ferramentas de software ou dados de serviços de comunicação. O conteúdo pode até ser direcionado para o tipo de dispositivo cliente que o está recebendo. Como as informações estão em um banco de dados, elas também podem ser compartilhadas e atualizadas mais facilmente com outros sistemas de negócios (por exemplo, quando os produtos são vendidos on-line ou em uma loja, a loja pode atualizar seu banco de dados de estoque).

##### Experiência de usuário personalizada

Os servidores podem armazenar e usar informações sobre clientes para fornecer uma experiência de usuário conveniente e personalizada. Por exemplo, muitos sites armazenam cartões de crédito para que os detalhes não precisem ser inseridos novamente. Sites como o Google Maps podem usar locais salvos ou atuais para fornecer informações de rota e histórico de pesquisa ou viagem para destacar empresas locais nos resultados da pesquisa. Uma análise mais profunda dos hábitos do usuário pode ser usada para antecipar seus interesses e personalizar ainda mais as respostas e notificações, por exemplo, fornecendo uma lista de locais visitados anteriormente ou populares que você pode querer ver em um mapa.

##### Acesso controlado ao conteúdo

A programação do lado do servidor permite que os sites restrinjam o acesso a usuários autorizados e forneçam apenas as informações que um usuário tem permissão para ver. Exemplos do mundo real incluem sites de redes sociais que permitem que os usuários determinem quem pode ver o conteúdo que eles postam no site e cujo conteúdo aparece em seu feed.

##### Armazenamento de informações de sessão/estado  

A programação do lado do servidor permite que os desenvolvedores façam uso de sessões — basicamente, um mecanismo que permite que um servidor armazene informações associadas ao usuário atual de um site e envie respostas diferentes com base nessas informações. Isso permite, por exemplo, que um site saiba que um usuário já fez login e exiba links para seus e-mails ou histórico de pedidos, ou talvez salve o estado de um jogo simples para que o usuário possa ir a um site novamente e continuar de onde parou.

##### Notificações e comunicação  

Os servidores podem enviar notificações gerais ou específicas do usuário por meio do próprio site ou por e-mail, SMS, mensagens instantâneas, conversas por vídeo ou outros serviços de comunicação. Alguns exemplos incluem:

- O Facebook e o Twitter enviam e-mails e mensagens SMS para notificá-lo sobre novas comunicações.
- A Amazon envia regularmente e-mails de produtos que sugerem produtos semelhantes aos já comprados ou visualizados nos quais você pode estar interessado.
- Um servidor da web pode enviar mensagens de aviso aos administradores do site, alertando-os sobre pouca memória no servidor ou atividade suspeita do usuário.

##### Análise de dados

Um site pode coletar muitos dados sobre os usuários: o que eles pesquisam, o que compram, o que recomendam, quanto tempo permanecem em cada página. A programação do lado do servidor pode ser usada para refinar respostas com base na análise desses dados. Por exemplo, a Amazon e o Google anunciam produtos com base em pesquisas (e compras) anteriores.
