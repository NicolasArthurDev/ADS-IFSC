Um servidor HTTP simples pode ser feito em Java usando uma pequena API composta por algumas classes:

- [HttpServer](https://docs.oracle.com/javase/8/docs/jre/api/net/httpserver/spec/com/sun/net/httpserver/HttpServer.html): uma classe abstrata que implementa um servidor HTTP capaz de atender requisições recebidas em um determinado IP e port
- [HttpHandler](https://docs.oracle.com/javase/8/docs/jre/api/net/httpserver/spec/com/sun/net/httpserver/HttpHandler.html): uma interface que representa um tratador de requisições. Um objeto _HttpHandler_ embute a lógica de processamento de requisições associadas a um contexto
- [HttpContext](https://docs.oracle.com/javase/8/docs/jre/api/net/httpserver/spec/com/sun/net/httpserver/HttpContext.html): uma classe que representa um contexto no qual requisições são tratadas. Um contexto é definido por uma URI base e um _HttpHandler_

Por exemplo, um servidor HTTP que retorna "_Hello world !_" para qualquer requisição recebida poderia ser assim:

```java
import com.sun.net.httpserver.HttpExchange;  
import com.sun.net.httpserver.HttpHandler;  
import com.sun.net.httpserver.HttpServer;  
  
import java.io.IOException;  
import java.io.OutputStream;  
import java.net.InetSocketAddress;  
  
// Um tratador deve implementar a interface HttpHandler  
class MeuHandler implements HttpHandler {  
  
    // O método handle é chamado para processar uma requisição.  
    // A requisição é representada por um objeto HttpExchange  
    @Override  
    public void handle(HttpExchange httpExchange) throws IOException {  
        // obtém um OutputStream para gerar o corpo da mensagem de resposta  
        OutputStream outputStream = httpExchange.getResponseBody();  
  
        // Esta é a resposta a requisições tratadas por este HttpHandler !  
        String htmlResponse = "Hello world !";  
  
       // Define o status da resposta, e o comprimento do corpo da mensagem  (em bytes)  
        httpExchange.sendResponseHeaders(200, htmlResponse.length());  
  
        // escreve o corpo da resposta  
        outputStream.write(htmlResponse.getBytes());  
        outputStream.flush();  
        outputStream.close();  
    }  
}  
  
public class Main {  
  
    public static void main(String[] args) throws Exception {        // Cria um servidor HTTP, que recebe requisições em localhost no port 8080 (e com backlog 0)HttpServer srv = HttpServer.create(new InetSocketAddress("localhost", 8080), 0);  
  
        // Cria um contexto para processar requisições em URIs iniciadas com "/"  
        // O tratador de requisições é um objeto MeuHandler  
        srv.createContext("/", new MeuHandler());  
  
        // Executa o servidor HTTP  
        srv.start();  
  
    }  
}

```

Este exemplo mostra que um pequeno servidor HTTP pode ser criado com _HttpServer_. Com ele, pode-se definir como cada requisição deve ser processada, dependendo da URI. Se requisições com URI iniciadas com "/_portugues_" precisarem ser processadas de forma diferente, basta definir um novo _HttpHandler_, e vinculá-lo a essa URI base por meio de um _HttpContext_:

```java
// Um tratador deve implementar a interface HttpHandler  
class MeuHandlerPortugues implements HttpHandler {  
  
    @Override  
    public void handle(HttpExchange httpExchange) throws IOException {  
        OutputStream outputStream = httpExchange.getResponseBody();  
  
        String htmlResponse = "Ola mundo !";  
  
        httpExchange.sendResponseHeaders(200, htmlResponse.length());  
        outputStream.write(htmlResponse.getBytes());  
        outputStream.flush();  
        outputStream.close();  
    }  
}  
  
public class Main {  
  
    public static void main(String[] args) throws Exception {        // Cria um servidor HTTP, que recebe requisições em localhost no port 8080 (e com backlog 0)HttpServer srv = HttpServer.create(new InetSocketAddress("localhost", 8080), 0);  
  
        srv.createContext("/", new MeuHandler());  
        srv.createContext("/portugues", new MeuHandlerPortugues())  
  
        // Executa o servidor HTTP  
        srv.start();  
  
    }  
}

```

#### Requisições e HttpExchange

Quando um _HttpHandler_ precisa processar uma requisição, são necessárias informações a ela associadas. Isso envolve a URI acessada, cabeçalhos HTTP, possíveis parâmetros embutidos na URI, e também o corpo da mensagem. Isso tudo pode ser obtido via objeto _HttpExchange_, o qual é passado como parãmetro do método _handle_ de _HttpHandler_. Existem métodos de _HttpExchange_ para acessar essas informações, sendo alguns deles:

- [URI getRequestURI()](https://docs.oracle.com/javase/8/docs/jre/api/net/httpserver/spec/com/sun/net/httpserver/HttpExchange.html#getRequestURI--): obtém a URI da requisição
- [Headers getRequestHeaders()](https://docs.oracle.com/javase/8/docs/jre/api/net/httpserver/spec/com/sun/net/httpserver/HttpExchange.html#getRequestHeaders--): obtém um tabela com os cabeçalhos da requisição, em que nomes de cabeçalhos são as chaves
- [String getRequestMethod()](https://docs.oracle.com/javase/8/docs/jre/api/net/httpserver/spec/com/sun/net/httpserver/HttpExchange.html#getRequestMethod--): obtém o método HTTP usado na requisição (GET, POST, ...)
- [InputStream getRequestBody()](https://docs.oracle.com/javase/8/docs/jre/api/net/httpserver/spec/com/sun/net/httpserver/HttpExchange.html#getRequestBody--): obtém uma stream para ler o corpo da requisição

Outros métodos podem ser vistos na [documentação da classe HttpExchange](https://docs.oracle.com/javase/8/docs/jre/api/net/httpserver/spec/com/sun/net/httpserver/HttpExchange.html).
