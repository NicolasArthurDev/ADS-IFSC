Beleza, vamos discutir cada um em um tópico:
## 1. Sem espaço para Projeto ✅
Como eu tinha visto anteriormente, seria melhor adicionar as estruturas (repositórios) dos projetos no Github e deixar anotado, podemos até ter uma pasta de projetos e contar os projetos por disciplina.

## 2. PDFs jogados ✅
Deixar uma pasta de `./Documentos` dentro de cada disciplina, o que iria repetir varias vezes, porém, deixariamos agrupados os slides dos professores

## 3. Dificil encontrar o fluxo de aulas ✅
Temos esses dois estilos:
- Começar a aula com `02-28 xxx` para mostrar o dia, e consequentemente mostrar a Timeline;
- Começar a aula com `0. xxx`, assim mostra a sequencia de cada coisa
Vou pela segunda opção

## 4. Aonde coloco as atividades ✅
Bem, no mesmo caso de "Sem espaço para projeto" e "PDFs jogados", podemos criar mais duas pastas dentro das disciplinas, sendo `Projetos` e `Atividades`, onde:
- `Projetos`: Ficaria todo projeto grande;
- `Atividades`: Toda lista, laboratorio e exercicio.

## 5. E os resumos? ✅
Eu e o meu irmão gostamos de fazer um resumo no sábado com o objetivo de resumir tudo o que vimos na semana. Assim poderiamos estudar de forma rápida e ir lembrando dos assuntos aprendidos.

Resumos poderiamos ter dentro de cada Semestre uma pasta dedicada a estes estudos.
