- [Uma implementação da fila](https://moodle.ifsc.edu.br/mod/page/view.php?id=313699&forceview=1):
    - Implemente sua fila no arquivo _src/esd/Fila.java_, no repositório de suas estruturas de dados 
    - Copie o arquivo [TestFilaSimples.java](https://moodle.ifsc.edu.br/pluginfile.php/633662/mod_label/intro/TestFilaSimples.java?time=1743210227815) para dentro da pasta test/
    - Para testar sua implementação, execute o gradle desta forma:

```bash
gradle test --tests TestFilaSimples
```
